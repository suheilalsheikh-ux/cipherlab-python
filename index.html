01 الخوارزمية الأولى

Caesar Cipher — شفرة قيصر

خوارزمية استبدال بسيطة: نزيح كل حرف بالمقدار نفسه، وهو عدد محدد يسمى المفتاح.

الفكرة في 3 خطوات

  1. 1
    حدّد موقع الحرفA=0، B=1، C=2 ... Z=25
  2. 2
    أضف المفتاح أو اطرحهفي التشفير نضيف (+)، وفي فك التشفير نطرح (−).
  3. 3
    استخدم باقي القسمة على 26لأن عدد الحروف 26؛ بعد Z نعود إلى A.
مثال: CAT بمفتاح 3 تصبح FDW، لأن C→F وA→D وT→W.

المعادلة سهلة!

E(x) = (x + k) % 26

E = Encrypt التشفير · x = رقم الحرف · k = المفتاح

D(x) = (x − k) % 26

D = Decrypt فك التشفير · علامة % تعني باقي القسمة.

لماذا % 26؟ الحرف Z رقمه 25، وإذا أضفنا 3 تصبح 28، وباقي قسمة 28 على 26 هو 2، أي الحرف C.

💻 اضغط لفهم الكود الأصلي في صورة Caesar

هذا هو جوهر دالة التشفير المعروضة في محاضرتكم:

caesar_cipher.pyPython
import string
alphabet = string.ascii_lowercase

def encrypt(plain_text, key):
    result = ""
    for letter in plain_text.lower():
        if letter in alphabet:
            current_index = alphabet.index(letter)
            new_letter = (current_index + key) % 26
            result += alphabet[new_letter]
        else:
            result += letter
    return result

02 الخوارزمية الثانية

Vigenère Cipher — شفرة فيجنير

تشبه Caesar، لكن بدل مفتاح رقمي ثابت نستخدم كلمة مفتاح؛ وكل حرف من الكلمة يحدد إزاحة مختلفة.

ما الفرق الكبير؟

في Caesar بمفتاح 3، كل حرف يتحرك 3 خطوات. في Vigenère بمفتاح KEY، تصبح الإزاحات 10 ثم 4 ثم 24 ثم نكررها.

HELLO+KEYKE→RIJVS
إذا كان النص HELLO والمفتاح KEY، نكرر المفتاح ليصبح KEYKE بنفس طول النص.

المعادلتان

Cᵢ = (Pᵢ + Kᵢ) % 26
Pᵢ = (Cᵢ − Kᵢ) % 26

Pᵢ = رقم حرف الرسالة · Kᵢ = رقم حرف المفتاح المقابل له · Cᵢ = رقم الحرف المشفّر. الرمز i يعني موضع الحرف.

مثال: الحرف H رقمه 7، والمفتاح K رقمه 10. إذًا (7 + 10) % 26 = 17، وهو الحرف R.

💻 اعرض جوهر الكود الموجود في الصورة
vigenere_cipher.pyPython
import math

def encrypt(plaintext, key):
    ciphertext = ''
    for (i, j) in zip(plaintext, key):
        p_text = ord(i.lower()) - ord('a')
        p_key = ord(j.lower()) - ord('a')
        newindex = (p_text + p_key) % 26
        newletter = chr(newindex + ord('a'))
        ciphertext += newletter
    return ciphertext

# تجهيز المفتاح في main()
c = math.ceil(len(plaintext) / len(key))
newkey = []
for i in range(0, c):
    for z in key:
        newkey.append(z)
newkey = newkey[:len(plaintext)]

في فك التشفير نستخدم (p_text - p_key) % 26. يفترض كود المحاضرة وجود مفتاح غير فارغ من الحروف الإنجليزية، وقد يتعامل مع الرموز والمسافات بطريقة غير مقصودة.
