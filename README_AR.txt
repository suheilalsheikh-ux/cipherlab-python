مختبر الشفرات Cipher Lab — تحديث محرّك Python (Version 2)
تصميم المهندس سهيل الشيخ

هذه الحزمة مخصصة لتحديث نفس المستودع الحالي cipherlab-python.
التغييرات:
- اعتماد Module Worker بدلاً من Classic Worker/importScripts.
- استخدام Pyodide 314.0.8 (Python 3.14) كما في الوحدة الرسمية التي نجحت على هاتفك.
- إضافة اختبار داخلي 2+3 قبل إعلان جاهزية Python.
- إضافة engine-check.html لعرض المراحل والخطأ المفصّل.
- تحسين العرض على شاشة الجوال وتحديث نسخة ملفات العامل لتجاوز التخزين المؤقت.

الخطوات على GitHub:
1. افتح مستودع suheilalsheikh-ux/cipherlab-python.
2. اختر Add file > Upload files.
3. ارفع ملفات index.html وpython-worker.js وengine-check.html من هذه الحزمة.
4. عندما يطلب استبدال ملفات بنفس الاسم في واجهة GitHub، التزم بطريقة GitHub المسموح بها للحفاظ على نفس المسار في جذر المستودع؛ إذا رفض الرفع المتكرر، افتح الملف الحالي واختر Edit (القلم) والصق محتوى الملف المعدّل.
5. اضغط Commit changes، ثم انتظر اكتمال نشر Netlify التلقائي للمستودع.
6. افتح https://suheil-cipherlab.netlify.app/engine-check.html وابدأ الفحص.
7. إذا ظهرت 5 ثم نجاح كامل، افتح الصفحة الأساسية وجرّب الدرس الأول.

مهم:
- لا ترفع ملفات الحزمة داخل مجلد فرعي جديد؛ يجب أن تبقى في جذر المستودع.
- هذه النسخة لم تُختبر من داخل الجوال عبر الإنترنت بعد، ويجب التحقق من ذلك قبل مشاركة المنصة مع الطلاب.
- تشغيل Python ما زال يحتاج إنترنت في أول استخدام.
